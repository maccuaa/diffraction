# Diffraction

A client-side tool for comparing two blocks of text or code and highlighting their differences.

## Language

**Original**:
The baseline text or code being compared against.
_Avoid_: Before, Source, Left, A

**Changed**:
The modified text or code being compared to the Original.
_Avoid_: After, Target, Right, B

**Diff**:
The line-level differences (additions, deletions, unchanged lines) computed between the Original and the Changed.
_Avoid_: Comparison, delta, patch
